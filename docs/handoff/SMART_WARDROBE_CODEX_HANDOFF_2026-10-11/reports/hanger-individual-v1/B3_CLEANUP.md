# B3 투명 에셋 수정

사용자의 최종 지시는 기존 B3 데님 셔츠의 크기·각도·좁은 측면 형태를 기준으로 사각형 조명 흔적과 배경을 제거해 투명 PNG로 재생성하는 것이다. 가공 전 옷장의 파란 상의를 가져오거나 상품 정면 사진을 배치하는 작업이 아니다.

`B3.png`를 포즈 기준으로 built-in `image_gen.imagegen`을 사용했다. 1·2차 생성본은 색 번짐과 폭 변경 때문에 채택하지 않았다. 최종 생성 원본은 `B3-clean-v4.png`이며 네이티브 Canvas에서 알파 색 번짐을 제거하고 경계를 1px 정리했다. PNG 원본 해상도는 721×2180이다. 비율을 유지해 기존 배치 캔버스 53×310에 맞춘 최종 파일은 `B3-clean-final.png`, 고해상도 정리본은 `B3-clean-highres.png`다. 메타데이터는 `B3-clean-placement.json`에 기록했다.

검수 화면은 `B3-clean-review.html`이다. 기존 에셋과 수정본을 같은 크기로 표시하며 밝은 체크무늬와 어두운 배경으로 비교할 수 있다. `review.html`에는 수정 B3를 기본 배치하고 `수정 B3 적용` 체크박스로 기존 에셋과 비교할 수 있게 했다. 기존 에셋 모드의 21벌 재합성은 기준 이미지와 일치한다. 수정 에셋 모드에는 그 일치 주장을 적용하지 않는다. 다른 의류 에셋, 앱, API, DB 및 운영 배포는 변경하지 않았다.

실제 브라우저에서 수정 B3의 배치·숨기기·이동과 오류 0을 확인했다. 기존/수정 전환의 변경 픽셀 12,548개는 B3 배치 캔버스 안에 있으며 밖은 0이다. `B3-clean-in-wardrobe.png`와 확대 캡처를 확인한 결과, 셔츠 주변에 기존 추출 배경의 밝은 나무 윤곽이 드러난다. 에셋 단독 정리와 별개로 배경 복원이 미완료라 자연스러운 최종 합성으로 승인하지 않는다.

투명 배경, 옆의 검정 옷·아래 배경 제거, 기존 캔버스 크기를 확인했다. 이미지 재생성 때문에 직물 디테일과 고리의 세부 형상은 원본 픽셀과 같지 않다. 좁은 측면 포즈를 유지하도록 생성했으나 완전한 실루엣 일치나 사용자 최종 승인을 주장하지 않는다. 조명 사각형 경계의 제거와 형태 품질은 비교 화면에서 시각적으로 판단한다.

재현:

```powershell
node scripts/prepare_b3_clean.mjs
```

이 명령은 저장된 최종 생성 원본의 Canvas 마감만 다시 수행한다. 이미지 생성 호출이나 유료 API 호출은 하지 않는다.
