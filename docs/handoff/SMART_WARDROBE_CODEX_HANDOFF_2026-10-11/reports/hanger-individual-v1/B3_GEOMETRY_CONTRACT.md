# B3 기준점 및 합성 계약

현재 검수 화면의 기준 계약은 [B3_GEOMETRY_CONTRACT.json](B3_GEOMETRY_CONTRACT.json)이다. 목표는 데님 셔츠를 원래 행거에 자연스럽게 배치하면서 고리·어깨·소매·몸판의 구조와 원본 배치 관계를 유지하는 것이다. 이미지 생성의 크기 지시만으로 배치를 확정하지 않는다.

배치 기준은 Codex 수정 전 원본 옷장 `reference-unchanged.png`다. 소재와 상품 정체성은 `candidate-photos/B3.jpg`의 데님 셔츠다. 원본 옷장의 파란색 상의는 기하 기준이며 상품 정체성 기준이 아니다. 조명 마스크·사각 합성본은 좌표나 투명 윤곽의 기준으로 사용하지 않는다. 좌표는 이미지에서 읽은 시연용 값으로 실물 측정값이 아니다.

주요 기준점은 원본 1672×941 좌표에서 다음과 같다. 전체 13점과 허용 범위는 JSON에 있다.

| 기준점 | 옷장 좌표 | 허용 범위 |
|---|---|---|
| 고리 상단 | 519, 123 | 1px |
| 고리 아래 줄기 | 517, 143 | 1px |
| 옷걸이 목 | 517, 156 | 1px |
| 왼쪽 어깨 | 500, 191 | 2px |
| 왼쪽 소매 중간 | 488, 310 | 2px |
| 커프스 상단 | 499, 375 | 2px |
| 커프스 하단 | 508, 405 | 2px |
| 몸판 밑단 오른쪽 | 533, 419 | 2px |
| 몸판 밑단 아래 | 515, 421 | 2px |

소매와 몸판은 분리되어 보여야 하고 가슴 포켓·단추선은 몸판에 있어야 한다. 커프스 아래로 몸판 밑단이 보이는 원본 관계를 유지한다. 이전 v5는 커프스와 몸판 끝의 관계가 달라 보정 후보에서 제외했다. 그 후보에 대한 첫 위치 보정도 뒤틀림과 기준점 실패로 채택하지 않았다.

새 생성 원본 `B3-contract-source-v7.png`는 원본 B3 측면 확대 이미지와 상품 사진을 참조해 built-in imagegen으로 만들었다. 고해상도 투명 정리본 `B3-contract-v7-highres.png`는 1122×1402이며 생성물의 여백을 배치 기준으로 쓰지 않는다. 수동으로 읽은 생성물의 동일 부위 기준점과 원본 목표점 사이에 결정적 좌표 보정을 적용했다. 최종 `B3-aligned-v8.png`는 **76×318 캔버스, 원점 480,115**다. 이 캔버스 크기는 빈 여백과 주변 오버랩 여유를 포함하므로 의류 크기 자체를 뜻하지 않는다. 보정은 4배 샘플링으로 수행한 뒤 축소해 직물의 픽셀 잡음을 줄였다.

수정 모드는 행거 전체 숨기기에서 사용하던 빈 배경 중 **B 구역 전체**를 먼저 그리고 B1–B6 개별 에셋을 순서대로 배치한다. B3 뒤에 옷 모양의 나무 패치를 넣지 않는다. B4가 B3 앞에 놓이는 기존 겹침 순서를 유지한다. B4 분리본의 바깥 나무 조각은 검수 렌더에서 수동 윤곽으로 제외했다. B4 PNG 원본이나 최초 분리본 비교 모드는 변경하지 않았다. 주변 옷에 색상 기준 자동 제거를 적용한 시험은 실제 의류를 잘라내므로 폐기했다.

검증을 분리한다.

- 계산 검증: 보정 계산의 기준점 오차와 좌표 대응을 확인한다. 이는 보정 설계 자체의 검사이며 시각적 정답을 증명하지 않는다.
- 출력 검사: 저장된 PNG의 목표 기준점 주변에 실제 알파가 존재하는지 확인한다. 가는 금속 고리는 축소 후 반투명해질 수 있어 64 이상, 직물·나무는 200 이상을 요구한다. 불투명 영역에서 국소 역전이 없는지도 확인한다.
- 실제 브라우저: 원본 보기, 새 B3, 숨기기·이동, 기준점 표시를 실행한다. B 구역 밖 변경 픽셀은 0이어야 한다. 최초 분리본 모드는 원래 기준 이미지와 픽셀 차이 0을 유지한다.
- 시각 검수: 전체 및 확대 캡처에서 소매/몸판 구분, 밑단 관계, 고리 배치, 옆옷 중첩, 배경 잔여물을 직접 본다. 숫자 통과만으로 원본과 완전 일치하거나 최종 승인됐다고 보고하지 않는다.

현재 수치·브라우저 검사는 통과했다. 직접 본 합성에서 이전의 짧은 B3와 밝은 나무 패치는 개선됐고 커프스 아래 몸판이 보인다. 원본과 다른 데님 소재·칼라·주름은 남는다. 주변 의류의 분리 가장자리도 완벽한 누끼라고 주장하지 않는다. **사용자 최종 시각 검수는 대기 상태**다. 나머지 의류 생성이나 제품 앱·API·DB 반영으로 확대하지 않았다. 원격 push·배포·유료 API 호출은 하지 않았다.

검수 화면의 `가공 전 원본 배치`, `B3 기준점 표시`, `수정 B3 적용`으로 비교한다. PNG와 캡처는 다음 파일이다.

- [기준점 보정 PNG](B3-aligned-v8.png)
- [실제 옷장 합성](B3-clean-in-wardrobe.png)
- [확대 합성](B3-clean-in-wardrobe-detail.png)
- [기준점 표시 캡처](B3-contract-guide-overlay.png)
- [기준점 출력 검사](B3-contract-anchor-check.json)

프로젝트 루트에서 재현:

```powershell
node scripts/prepare_b3_clean.mjs B3-contract-source-v7.png B3-contract-v7
node scripts/align_b3_landmarks.mjs
node scripts/verify_hanger_extraction.mjs
```

이 명령들은 저장된 생성물 마감·좌표 보정·로컬 검수만 수행한다. 새 이미지 생성이나 유료 API 요청은 하지 않는다.
