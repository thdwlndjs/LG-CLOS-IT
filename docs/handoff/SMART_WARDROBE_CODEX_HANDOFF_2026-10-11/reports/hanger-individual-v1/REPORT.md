# 행거 의류 개별 분리

요구사항은 찾기 순간에만 누끼를 적용하는 것이 아니라, 평상시부터 각 의류를 별도 투명 에셋으로 배치하는 것이다. 원본 기준은 승인된 `../wardrobe-visual-samples-v1/wardrobe-composite.png`이며 새 이미지 생성 없이 원본 RGB 픽셀을 분리했다.

현재 산출물은 A1–A7 코트, B1–B6 상의, C1–C8 하의의 **투명 PNG 21개**와 배치 좌표다. 원본의 보이는 픽셀을 이 PNG들에 배분했다. 원래 위치에 모두 배치한 `recomposed.png`는 기준 이미지와 RGBA 픽셀 차이가 0이다. 확대·회전·색상 변경은 하지 않았다. 옷걸이와 고리도 각 의류에 포함한다. 오른쪽 선반과 왼쪽 하단 접힌 옷은 이번 분리 대상이 아니며 배경에 남아 있다.

`review.html`에서 원본/재합성 전환, 21벌 각각 숨기기, 오른쪽 80px 이동, 전체 행거 숨기기, 개별 투명 PNG를 확인할 수 있다. `hanger-empty-background.png`는 윤곽 밖의 원본 픽셀을 보존하는 기본 복원 배경이다. 제거·이동 시에는 공통 배경 `hanger-clean-underlay.png` 중 해당 A/B/C 행거 구역 전체를 복원해, 옷 형태의 밝은 나무 패치가 남는 현상을 피한다. 이때 해당 구역의 나무와 그림자는 기존 빈 옷장 에셋의 모습으로 바뀐다. 따라서 제거 화면까지 원본과 동일하다는 의미는 아니다.

분리는 수동 윤곽과 보이는 픽셀의 소유 영역을 이용했다. 인접 윤곽 사이의 잔여 픽셀을 의류에 배정했으므로 일부 배경/옆옷 경계가 포함될 가능성이 있다. **재합성 차이 0은 누끼 가장자리의 정확성을 증명하지 않는다.** 배경을 모두 숨긴 화면과 A5/B3 개별 제거 화면을 실제 확인했고, A5 밑단의 잔여 조각을 수정했다. 모든 21벌의 가장자리 품질과 임의 재배치를 완료 승인한 상태는 아니다.

가려진 의류 뒷부분은 원본에서 얻을 수 없어 복원하지 않았다. 현재 에셋은 원래 겹침 상태의 보이는 부분이다. 옷을 크게 이동하거나 겹침 순서를 바꾸면 누락된 부분이 드러날 수 있다. 현재 요청의 원래 배치 재현과 독립 분리 검증은 구현했지만, 자유로운 재배치용 완전한 의류 에셋 완성으로 보고하지 않는다.

브라우저 검증은 원본과 재합성 일치, 21개 숨기기 액션, A5/B3 이동 캡처, 페이지 오류 0을 확인했다. 검증 범위는 로컬 에셋 검수 화면이며 제품 앱·API·DB·조명 상태 전환 반영은 이번 단계에서 변경하지 않았다. 운영 반영, 원격 push, 배포도 수행하지 않았다.

재현 명령:

```powershell
node scripts/extract_hanger_pixels.mjs
node scripts/verify_hanger_extraction.mjs
```

검수 서버가 실행 중이면 `http://127.0.0.1:5194/hanger-individual-v1/review.html`에서 확인한다. 서버가 없으면 프로젝트 루트에서 다음 명령으로 실행한다.

```powershell
.venv/Scripts/python.exe -m http.server 5194 --bind 127.0.0.1 --directory docs/handoff/SMART_WARDROBE_CODEX_HANDOFF_2026-10-11/reports
```

다음 작업은 의류별 가장자리 정교화, 필요한 가려진 부분 복원, 평상시/어두움/밝음 개별 에셋, 기존 Scene API의 실제 의류 ID 매핑이다. 기존 단일 전체 이미지 기반 조명 검수는 이번 개별 분리 구조의 앱 반영 완료를 의미하지 않는다.
