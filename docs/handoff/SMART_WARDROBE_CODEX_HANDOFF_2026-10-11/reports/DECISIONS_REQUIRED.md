## G1 승인 필요 결정

아래는 권리·시연 규모·실측·기존 계약 호환성에 필요한 결정이다. 가족 관리/엄마·아들/보유-only/간절기 유지/수동 완료/4개 카드 자체는 이미 확정되어 다시 선택하지 않는다.

| ID | 질문 | 추천 | 다른 선택/미결 영향 |
|---|---|---|---|
| D01 | 최초 승인할 가족·품목 규모 | 엄마/아들 2명 + 여름3/겨울2 + 아들1룩 최소셋 | 4인/51개 전체는 후속 승인; P3 seed namespace와 수량 미확정 |
| D02 | 공식 이미지와 참고 원본의 사용·공개 권한 | 권리 확보한 원본 또는 직접 촬영본만 생산/배포 | 허가 전 로컬 참조 전용; 권리 미해결 asset 생성/공개 gate blocked |
| D03 | 슬롯·외부공간·실제 용량 확인 | A–G 실측; 외부 room2/entry는 후보만 | 사진상의 35/51 숫자 채택 금지; 좌표/용량/환경 최적성 증명 불가 |

공식 제품 실재성·이미지 권리·시연 보유 설정·공간 실측은 서로 다른 승인이다. PC12/13과 원본 이미지 부족은 사용자 선택만으로 검증됐다고 바꾸지 않는다. 실제 소재/색상 불명 제품을 임의 대체하지 않는다. 모호한 품목은 재조사하거나 승인셋에서 제외한다.

G1은 승인된 candidate/instance/space/asset manifest와 구현 범위를 고정하는 게이트. 지금 DB에 적재된 상태를 의미하지 않는다. 현재 로컬/클라우드 데이터 수는 직접 조회하지 않았고 기존 고객 의류를 삭제하거나 새 시연 데이터로 덮어쓰지 않았다.
