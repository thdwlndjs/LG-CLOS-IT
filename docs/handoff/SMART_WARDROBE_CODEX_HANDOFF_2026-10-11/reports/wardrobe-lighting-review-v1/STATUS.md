# 의류 찾기 조명 검수

의류 6개와 현재 진행상황은 사용자 승인 완료. 다음 게이트는 의류 표면 조명 검수다.

검정 코트 칸·데님 셔츠 칸·접힌 니트 칸의 표면 조명 참고 이미지를 생성하고, 비선택 수납칸 감광·동시 선택·자동 소등을 검수 화면에서 연결한다. 앱·DB·운영 저장소 반영과 나머지 에셋 생성은 조명 검수 후 진행한다.

현재 상태: 기존 조명안 전반은 사용자 긍정 평가. 추가 요청으로 행거는 해당 의류 섹터만 밝히고 같은 칸의 옆옷도 감광하도록 수정했다. 선반 조명 유지. 수정본 검수 대기. 재개 기준은 `REVIEW.md`와 `lighting.json`이다.
