# 먼저 읽어 주세요 — 플랫레이 코디카드 팀 검토본

## 이 ZIP은 무엇인가요?

옷을 고르면 자동으로 한 장에 배치하고, 이름 입력이나 피팅 없이 조합을 저장·수정·재사용할 수 있는 **독립 실행본**입니다. 팀 웹 https://lg-clos-it.vercel.app/ 에는 아직 통합되지 않았습니다. 현재 팀원 코드를 덮어쓰지 말고 별도 폴더에서 체험하세요.

김수진·최휘재와 의류는 가상 시연 데이터입니다. 실제 계정·소유·구매 상품·착용 기록이 아닙니다. 기존 제공 컷아웃32개로 시연 보유 레코드32개와 외부 후보2개를 표현합니다. 실제 인물 사진이나 영상은 없습니다.

## 가장 쉬운 실행 방법 (Windows)

1. ZIP을 모두 압축 해제합니다. ZIP 안에서 실행하지 마세요.
2. **`SmartCloset_Flatlay_CodiCard_TeamReview_20261011` 폴더**를 엽니다. `README_FIRST.md`, `package.json`, `START_WINDOWS.cmd`가 함께 있는 곳입니다.
3. **Node.js 22 이상**이 필요합니다. 실제 검수 환경은 Windows / Node.js 24.18.0입니다. 없으면 [Node.js 공식 사이트](https://nodejs.org/)에서 설치하고 새 창을 엽니다.
4. `START_WINDOWS.cmd`를 더블클릭합니다. 오류가 있어도 창이 바로 닫히지 않습니다.
5. 브라우저에서 **http://127.0.0.1:4391/** 을 엽니다. 서버 창은 켜 두세요.

실행에 필요한 npm 외부 패키지는 **0개**입니다. 가입·로그인·Supabase·API 키 설정이 필요하지 않고 유료 API도 호출하지 않습니다.

터미널을 이용한다면 이 폴더에서 다음을 실행합니다. `npm ci`는 잠금 파일 확인용이며, 외부 의존성이 없어 설치 다운로드 없이 통과합니다.

```powershell
node --version
npm ci --ignore-scripts --offline
npm run check
npm test
npm start
```

`EADDRINUSE`는 다른 서버가 같은 포트를 쓰고 있다는 뜻입니다. 임의 프로세스를 종료하지 말고 기존 시연 창을 확인하거나 다음처럼 다른 포트를 사용하세요.

```powershell
$env:FLATLAY_PORT='4392'
npm start
```

이때 주소는 http://127.0.0.1:4392/ 입니다. `.env.example`은 설명용이며, 서버가 `.env` 파일을 자동으로 읽지는 않습니다.

## 직접 체험하기

- 오른쪽 위 **마이 · 프로필 이름**을 눌러 김수진 또는 최휘재를 선택합니다. 프로필마다 옷 목록·초안·저장 카드가 나뉩니다.
- 종류(상의/하의/신발 등)를 누르고 옷 사진을 선택합니다. 카드가 자동으로 구성됩니다. 다른 상의를 고르면 하의·신발·가방은 유지됩니다.
- **자연스럽게 / 정돈해서**로 배치를 바꿀 수 있습니다. 구성품 이름 옆 ×로 해당 품목만 뺍니다.
- **카드 저장**을 누릅니다. 이름은 선택 사항이며 빈칸이면 조합에서 자동으로 정합니다. 옷을 한 벌도 선택하지 않으면 저장하지 않습니다.
- 상단 **저장 카드**에서 카드를 누르면 원본을 보존한 새 초안으로 열립니다. 상의 등을 바꿔 저장하면 새 조합이 추가됩니다. 바꾸지 않고 재저장하면 중복 생성하지 않습니다.
- **외부 후보 예시**는 시연용 구매 후보입니다. 실제 수집 상품이나 보유옷이 아니며 LED·실제 착용으로 자동 승격되지 않습니다.
- **PNG 내보내기**로 현재 조합 이미지를 다운로드합니다. 내보내기는 카드 저장과 별개입니다. 저장 뒤 옷을 바꿨다면 저장 카드에서 다시 열어 내보내면 그 카드의 조합이 출력됩니다.

대표 체험: ① 휘재에서 블루 셔츠·데님·스니커즈·가방 선택 → 저장 → 상의만 교체 → 새 카드 저장 → 원본 재조회. ② 수진에서 셔츠·하의·신발·가방 + 외부 후보 조합 → 저장/PNG → 프로필 왕복 → 새로고침 후 재조회.

## 저장은 어디에 남나요?

**현재 브라우저의 localStorage**에 저장됩니다. 같은 주소와 브라우저에서 새로고침·서버 재실행 후 유지됩니다. 원격 DB 저장이나 계정 동기화는 아닙니다. 다른 브라우저, 시크릿 모드, 다른 포트/localhost 표기, 브라우저 데이터 삭제 시 동일 자료를 볼 수 없습니다. ZIP에는 제작자의 카드·세션·개인 저장소를 넣지 않았습니다.

저장소 오류나 다른 탭과의 충돌이 나면 안내를 보고 새로고침하세요. 기존 내용을 임의로 초기화하지 않습니다. 이미지가 없거나 로드에 실패하면 다른 옷으로 대신하지 않고 오류를 표시합니다.

## 되는 것 / 아직 안 되는 것

| 구분 | 상태 |
|---|---|
| 자동 배치·선택/교체·두 프로필·저장/재사용·PNG | 실제 로컬 실행 검증 |
| 보유/외부 후보·사진·프로필 | 가상 시연 데이터, 실제 소유 아님 |
| 실제 OpenAI 추천·Decart 피팅 | 미연결·실호출0회, mock 성공으로 대신하지 않음 |
| 팀 인증·원격 DB 저장·홈/달력 연결·실물 LED | 이 독립본에는 미통합; 기존 팀 계약에 연결 필요 |
| 실제 인물·피팅 영상 | 포함/생성하지 않음 |

API 관련 순수 입력/검증/장식 없는 참조 준비 함수는 있습니다. `reference/prototype/api/`의 OpenAI 파일은 **실행되지 않는 참고 코드**이며 앱이 import하지 않습니다. 앱을 실행하거나 카드를 저장해도 과금하지 않습니다. 팀 서버의 실제 권한·예산 gate와 승인 자산을 확인하기 전에는 연결하지 마세요.

## 개발 담당자에게

`INTEGRATION_GUIDE.md`에 파일별 역할과 기존 코디/마이·저장·홈/VTON/달력 연결 지점이 있습니다. 팀 소스/ID가 미확인이라 기존 파일명을 추측하거나 새 DB 구조를 만들지 않았습니다.

검증 결과는 `VERIFICATION.md`, 버전/포함·제외 내역은 `PACKAGE_INFO.json`, 전체 파일 SHA256은 `MANIFEST.sha256`입니다. `evidence/`에는 시연 데이터로만 조작한 실제 화면과 녹화가 있습니다.

추가 브라우저 검사를 원하는 개발자만 Playwright 1.55.1과 Chrome을 준비합니다. 앱 실행에는 필요 없습니다.

```powershell
npm install --no-save --package-lock=false --ignore-scripts playwright@1.55.1
npx playwright install ffmpeg
node tests/browser-check.mjs
```

Chrome이 표준 위치에 없으면 `CHROME_EXECUTABLE`에 설치 경로를 지정합니다. 별도 설치한 Playwright를 쓰면 `PLAYWRIGHT_MODULE`에 해당 `index.mjs` 경로를 지정할 수 있습니다. 검사 서버는4393, 새 격리 브라우저 저장소를 사용하며 외부 네트워크를 차단합니다. 실제 고객 데이터나 공급자 API 시험이 아닙니다.
