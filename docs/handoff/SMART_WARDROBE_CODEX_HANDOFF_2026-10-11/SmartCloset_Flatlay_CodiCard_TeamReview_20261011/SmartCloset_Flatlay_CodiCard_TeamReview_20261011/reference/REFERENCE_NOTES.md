# 보존한 참고 자료

`prototype/assets`와 `data`는 제공된 가상 시연 자료입니다. 원본/표시 파생물의 hash와 ID 관계는 demo-pack.json에 있습니다. 실제 소유나 공급자 전송 승인을 뜻하지 않습니다.

prototype/index.html/style.css/src는 비교 검수용 원본 시안입니다. **팀원 실행 시작점은 ZIP 루트 START_WINDOWS.cmd**입니다. 중복된 self-contained HTML은 포장 용량과 시작점 혼동을 줄이기 위해 제외했습니다.

prototype/api의 helper와 readiness JSON은 원본 참고 자료이며 현재 서버 설정이나 실연동 결과가 아닙니다. 정적 서버에서 실행/노출되는 API가 없고, 카드 UI가 import하지 않습니다. 팀의 기존 서버 권한·영속 비용 gate·버전/자산 승인을 확인하기 전에는 실행하지 마세요.
