# CHG-01/02/04 + SW-CARD-TEMPLATE-001 — 화면·피팅·코디카드 계약

> **PoC A1 적용(2026-10-11):** [최신 기준 계약](../POC_CONTRACT_A1.md)이 이 문서의 상충 조항보다 우선한다. 보유 코디 확정=착용1회, LED30초, 관심/혼합 VTON, 홈 미저장 PNG, 구매동기화 제외, 가이드 전용 케어 및 단계별 승인은 A1 기준이다. 아래 종전 정책/기술 경로는 상충 범위에서 이전 기준이며 현재 코드의 구현 완료를 뜻하지 않는다. A단계는 문서만 변경했고 B~G는 별도 승인 전 미착수다.

## AI 입어보기 IA

- CTA `AI 입어보기`; 기존 중복 `미러로 비교`/`미러로 입어보기`와 불필요한 비교 중간 화면 제거.
- 홈 추천 코디 **2~3개 가로 캐러셀**, 별도 `추천 코디 비교하기` 메뉴 만들지 않음.
- 홈/내 코디/코디 생성·편집/과거 캘린더/의류 상세(코디 구성 후)에서 기존 IA와 일치하는 진입점 제안. 실제 화면 없는 곳에는 사용자 승인 없이 별도 탭·화면 추가 금지.
- 선택 중인 item ID 목록 및 아바타/사진 상태를 VTON에 전달. 뒤로 가기 때 출발 화면·편집 중인 코디·캐러셀 선택/스크롤 위치 유지.
- `idle → preparing → running → succeeded | failed | cancelled`로 상태 구분. 실패해도 코디 편집·카드 생성 가능.

## VTON 실제 연동

- 실시간 카메라 기반과 정적 인물 이미지 기반은 **입력 파이프라인이 다름**. Decart 공식 지원 API·제품 범위·계약/가격·이미지 다중 입력 여부를 실제로 확인하고 각 모드 지원 유무를 명시.
- 정적 이미지 VTON이 제공된다고 가정하지 않음. 상·하의 동시 입력을 지원한다고 가정하지 않음.
- 미지원이면 `blocked`와 검증 가능한 대안을 작성. Mock을 실제 API 성공으로 표기하지 않음.
- API 키는 서버 환경변수만, 브라우저 번들/문서/로그/캡처에 노출 금지. 사진 동의/보존/삭제 정책은 기존 계약 대조.

## 코디 확정/카드 상태

- `이 코디 입기`: 의류 선택 확정 + 위치 안내 + 내부 LED 점등 요청. 이것만으로 실제 착용 완료가 아님.
- `착용 예정`, `실제 착용`, `카드 생성 요청` 모두 별도 이벤트.
- 카드 생성 CTA: 홈에서 코디 선택 후, 코디 편집/저장된 코디, AI 입어보기 결과, 코디 확정 직전, 과거 코디. 기존 IA 대조해서 중복 버튼을 만들지 않음.
- 카드 생성은 **사용자 호출**로만 시작, 추천의 자동 부작용 금지. VTON 없이 카드 생성 가능. 카드 이미지 입력은 보유 아이템 개별 에셋, VTON 합성 사진 자동 사용 금지.

## 4개 독립 편집형 카드 템플릿

- **상세 원본 계약**: `references/card/CARD_TEMPLATE_CONTRACT.md`가 이 문서보다 더 상세하고 우선되는 **템플릿 복원 기술 규격**. 원본 `references/card/T1_reference.png` ~ `T4_reference.png`를 사용.
- T1–T4는 **서로 다른 물체 배치·접힘·가림·광원·그림자**. 공통 카드 한 장을 CSS 변형하는 것은 불합격.
- 원본 픽셀/마스크/좌표/변환행렬/occlusion 기반 레이어 복원. 제목/하단 텍스트·어두운 오버레이 제거. 가려진 진짜 픽셀의 무손실 복원 불가 사실과 재구성 영역 기록.
- React 4개 레이아웃+Playwright PNG, 템플릿 버전/원본·파생 asset 버전/저장 자산 ID 추적. 서명 URL을 DB에 영속 저장하지 않음.
- Gate A: 템플릿별 원본 기반 재조합 시각 검증, Gate B: 새 실재 제품 이미지 치환+기하/색상 품질, Gate C: 배포 환경에서 생성→저장→조회 검증.
- 템플릿 복원과 **다른 의류를 원래 접힘 형태로 재표현하는 것**은 별도 문제. 품질 부족 시 `manual-review-required`/`unmodified-cutout` 등의 보수적 폴백.
- 자동 SNS 게시와 미승인 상품 혼입은 범위 밖. 공유용 PNG 다운로드/네이티브 공유 가능 여부는 현행 UX와 대조.
