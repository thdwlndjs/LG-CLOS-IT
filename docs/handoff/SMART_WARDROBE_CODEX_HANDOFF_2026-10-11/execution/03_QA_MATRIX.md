# QA / 수용 기준 매트릭스

> **PoC A1 적용(2026-10-11):** [최신 기준 계약](../POC_CONTRACT_A1.md)이 이 문서의 상충 조항보다 우선한다. 보유 코디 확정=착용1회, LED30초, 관심/혼합 VTON, 홈 미저장 PNG, 구매동기화 제외, 가이드 전용 케어 및 단계별 승인은 A1 기준이다. 아래 종전 정책/기술 경로는 상충 범위에서 이전 기준이며 현재 코드의 구현 완료를 뜻하지 않는다. A단계는 문서만 변경했고 B~G는 별도 승인 전 미착수다.

| ID | 시나리오 | 통과 기준 | 전제 |
|---|---|---|---|
| DATA-01 | 등록된 모든 실제 제품 | 검증된 실재 상품 URL/브랜드/품번(있는 경우)/이미지 출처 | RULE-01 |
| DATA-02 | 원본/파생 에셋 | 원본 출처·hash/변환 버전, 파생 타입 구분 | 에셋 권한 |
| DATA-03 | 한 아이템의 현재 위치 | FK 유효, 현재 공간 1개, 슬롯 중복 없음 | DB |
| DATA-04 | 동일 시드 2회 실행 | 중복 제품·아이템·슬롯/이력 없음 | 로컬 격리 DB |
| DATA-05 | 승인/완료 분리 | 제안 수락만으로 아이템 위치 변경 없음; 완료 확인 후 변경 | 이동 모델 |
| WARD-01 | 옷장 표시 아이템 | 배경 고정 옷 제거; 렌더 아이템과 DB 슬롯 대응 | clean plate |
| WARD-02 | 위치 찾기 | 해당 슬롯 표시, 연결 구획 LED만 점등, 자동 소등 | Mock/실기기 표기 |
| WARD-03 | 코디 확정 | 여러 구획 LED 중복 없는 요청, 착용 기록 자동 없음 | item ID |
| UX-01 | 홈 추천 | 2~3개 가로 캐러셀, 별도 비교 메뉴 없음 | 추천 데이터 |
| UX-02 | AI 입어보기 복귀 | 선택 ID/캐러셀 인덱스/편집 상태 보존 | 상태 모델 |
| VTON-01 | 카메라·사진 경로 | 실제 공식 지원 범위만 성공 주장; 거부/실패/취소 처리 | Decart 확인 |
| CARD-A | T1~T4 독립 원본 복원 | 원본 배치/광원/레이어·마스크 비교 QA 4개 별도 통과 | 기준본/계약 |
| CARD-B | T1~T4 신규 의류 치환 | 색상/로고/접힘/비율/가림/소품 슬롯 적합성 | 등록 아이템 |
| CARD-C | Playwright 서버 렌더 | 지정 캔버스 PNG·저장/재조회, 같은 버전 같은 결과 | 배포 환경 |
| CARD-01 | VTON 없이 카드 생성 | 직접 생성 가능, 미등록 아이템 차단, 착용 기록 자동 없음 | 선택 코디 |
| AGENT-01 | 여름 의류 반출 | 반팔·민소매·얇은 의류 우선, 최근 착용/일정 예외 설명 | 정책 |
| AGENT-02 | 경계 의류 기본 유지 | 트렌치/데님재킷/가디건/긴팔 자동 반출 금지 | 정책 |
| AGENT-03 | 겨울 회수 | 패딩/울코트/겨울 니트; 적절한 목표 공간·용량 검사 | 공간/상품 |
| AGENT-04 | 엄마 이동 완료 | 승인→실물 일괄 이동 확인→DB/검색/옷장 갱신 | 상태 모델 |
| E2E-01 | 엄마→아들 전체 시연 | 엄마의 가족 보관 제안 후 실제 완료 → 아들이 등록 의류 추천/피팅/카드 | 초기 시드 |
| E2E-02 | 실패 복구 | 서명 URL 만료, 네트워크 실패, LED 오프라인, 사진 동의 거부 시 안전한 실패 | 통합 |

**상태값**: `not_run`, `pass`, `fail`, `blocked`. 계획만 작성한 것을 `pass`라고 적지 않는다. P0~P2 단계에서는 구현 QA를 `not_run`으로 두는 것이 정상.
