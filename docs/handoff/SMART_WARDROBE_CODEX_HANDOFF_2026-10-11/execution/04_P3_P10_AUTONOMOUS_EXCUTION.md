\# Smart Wardrobe — G1 승인 / P3\~P10 자율 연속 실행

> **PoC A1 적용(2026-10-11):** [최신 기준 계약](../POC_CONTRACT_A1.md)이 이 문서의 상충 조항보다 우선한다. 보유 코디 확정=착용1회, LED30초, 관심/혼합 VTON, 홈 미저장 PNG, 구매동기화 제외, 가이드 전용 케어 및 단계별 승인은 A1 기준이다. 아래 종전 정책/기술 경로는 상충 범위에서 이전 기준이며 현재 코드의 구현 완료를 뜻하지 않는다. A단계는 문서만 변경했고 B~G는 별도 승인 전 미착수다.

앞서 확정한 D01\~D09를 최종 승인한다. 직전 G1 지시문의 모든 결정과 구현 원칙을 유지한다.



이제 P3부터 P10까지 가능한 작업을 순차·병렬로 수행하라. 사용자가 자리를 비우는 동안 중간 확인을 요청하기 위해 전체 작업을 중단하지 마라.



\## 1. 실행 범위



\- \*\*P3:\*\* 실제 상품 기반 데모 데이터·이미지 에셋·DB seed·clean plate 구축

\- \*\*P4:\*\* DB 기반 동적 옷장, 위치 조회, 슬롯 표시, Mock LED

\- \*\*P5:\*\* 홈 추천 캐러셀, AI 입어보기 진입점, 화면 상태 복원 및 UX 통합

\- \*\*P6:\*\* Decart VTON 정적·실시간 지원 범위 검증 및 가능한 연동 구현

\- \*\*P7:\*\* 코디카드 T1\~T4 독립 복원, 실제 의류 치환, React+Playwright PNG 생성·저장

\- \*\*P8:\*\* 계절별 보관·회수 에이전트, 수동 일괄 이동, 완료 시 DB 갱신, 동시성 처리

\- \*\*P9:\*\* 엄마·아들 시연 시나리오 기반 전체 E2E 및 회귀 테스트

\- \*\*P10:\*\* 최종 통합 검수, 문서 정합성, 잔여 결함 정리, 인계 보고서 작성



\## 2. 자율 실행 규칙



다음 작업은 추가 승인 없이 진행한다.



\- 기존 코드 분석·수정·리팩터링

\- 계약서·FSD·API 문서 갱신

\- 로컬 이미지 가공 및 템플릿 구현

\- 격리된 로컬 테스트 DB의 migration·seed·rollback

\- 무료·로컬 테스트, Playwright 캡처

\- Mock API·센서·LED 구현

\- 단위·통합·E2E 테스트

\- 검증된 작업의 로컬 커밋



작업 중 오류가 발생하면 원인을 분석하고 수정 후 재검증하라. 한 번의 실패로 중단하지 마라.



\## 3. 중단하지 말고 격리할 항목



다음 문제가 발생하면 해당 작업만 `BLOCKED`로 표시하고, 독립적으로 가능한 다른 작업을 계속 진행한다.



\- Decart API 키 부재 또는 유료 호출 필요

\- 외부 서비스 인증·제휴 권한 부재

\- 실제 하드웨어 부재

\- 원본 이미지 또는 상품 자료 부족

\- 실제 사용자의 시각 승인 필요

\- 외부 네트워크·도구 장애



이 경우 인터페이스와 테스트 가능한 Mock 경로를 완성하고, 실제 검증이 남았음을 명확히 기록하라.



단, 필수 선행조건이 충족되지 않은 기능을 완료 처리하거나 Mock 성공을 실제 연동 성공으로 보고하지 마라.



\## 4. 안전 경계



다음 작업은 이번 승인에 포함되지 않는다.



\- 운영·클라우드 DB 변경 및 삭제

\- 원격 push·merge·배포

\- 유료 API 호출 및 결제

\- 기존 사용자 데이터 삭제·초기화

\- 다른 팀원의 작업물 강제 덮어쓰기

\- 비밀키 노출 또는 저장소 커밋



기존 브랜치와 미커밋 변경을 보존하라. 충돌 위험이 있으면 별도 브랜치나 격리된 작업 영역을 활용하라.



\## 5. 품질 기준



1\. 실제 브랜드·제품 데이터와 합성 데모 맥락 데이터를 구분해 관리한다.

2\. 보유 의류와 LIKED 상품 모두 VTON 입력을 지원한다.

3\. 보관 추천의 승인과 실제 이동 완료를 분리한다.

4\. 옷장 표시·DB 위치·LED 영역의 정합성을 검증한다.

5\. 코디카드 4종은 서로 다른 독립 템플릿으로 구현한다.

6\. 기존 팀원 코드와 API 호환성을 가능한 범위에서 유지한다.

7\. 테스트 실패를 숨기지 않고, 수정 불가능한 항목은 재현 절차와 함께 남긴다.
