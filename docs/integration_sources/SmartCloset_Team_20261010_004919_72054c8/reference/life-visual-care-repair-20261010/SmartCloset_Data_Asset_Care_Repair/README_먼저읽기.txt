SmartCloset 233839 회귀 복구용 Codex 인계

전달: 기존 Codex 채팅/작업폴더에 이 ZIP을 제공하고 CODEX_START.txt를 붙여 넣습니다.
진행 중 다른 변경이 있으면 같은 파일을 동시에 수정하지 않고 현재 상태를 확인해 순차 진행합니다.

주요 파일
- Codex_생활데이터_기존이미지_LED_케어통합복구_최종지시.txt: 이번 후속 수정 지시.
- mapping_candidates.review.json: 두 원본팩의 32개 의류에 대한 대응 후보. 현재 앱의 확정 매핑/DB import 파일이 아닙니다.
- SOURCE_AUDIT.json: 입력 아카이브의 실제 검사 및 확인 범위. 현재 앱 코드/DB/브라우저 저장 검사가 아닙니다.
- evidence/: 사용자가 보낸 이미지와 영상의 일부 비교 캡처, 기존 카탈로그 발췌.

확인 결과
옛 카탈로그 48개 PNG는 입력 ZIP 안에서 모두 디코딩되며 해시가 일치하고 알파 채널이 있습니다.
생활팩의 32개 의류는 사진·피팅·실물 라벨·물리위치·LED 연결이 모두 미확정 상태입니다.
원본번호 S01~S07/H01~H05는 두 팩에서 서로 다른 품목을 뜻합니다.
SRC-P04의 조사 메모와 첨부 고객 화면의 문장이 일치합니다.

이 분석으로 현재 Codex가 파일을 삭제했다고 확정할 수는 없습니다.
실제 앱에서는 프로필/namespace, 원본ID, 이미지 경로/필드, 장면 배치 resolver, null 병합,
케어 selector를 추적해야 합니다.

이번 범위
로그인 없는 로컬 생활 프로필에서 기존 이미지·시연 LED를 재연결하고, 새 기록과 케어를 보존합니다.
원본을 합쳐 다시 만드는 대체 옷팩이 아닙니다. 새 이미지 생성/상품 수집/운영 DB 쓰기/유료 API 실행 없음.

대응 후보 주의
11개는 종류·색·형태 기준의 강한 시연 후보, 5개는 예시용 대조 필요,
10개는 명확한 차이나 추가 검토가 필요하고 6개는 이 아카이브에서 적합 후보 미확인입니다.
이 분류는 실제 상품/브랜드/SKU/실물 위치 동일성 검증이 아닙니다.
현재 앱에 추가 자산이 있으면 더 정확한 대응이 가능할 수 있습니다.

케어
실제 라벨, 공식 상품 안내, 시연 참고, 검증 전 자료를 분리합니다.
영문 발췌와 내부 notes를 합친 문자열을 고객 안내로 쓰지 않습니다.

이 패키지 작성 시 앱 코드 변경·DB 적용·API 호출·원격 push는 실행하지 않았습니다.
