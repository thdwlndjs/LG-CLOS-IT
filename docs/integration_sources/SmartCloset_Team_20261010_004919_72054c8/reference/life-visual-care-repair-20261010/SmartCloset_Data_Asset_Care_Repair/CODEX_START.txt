현재 프로젝트에서 첨부
Codex_생활데이터_기존이미지_LED_케어통합복구_최종지시.txt
전체를 읽고 구현·실제 브라우저 검수까지 진행해.

새 생활 데이터에서 사진과 LED가 빠지고 케어에 내부 조사 메모가 노출되는 회귀를 고치는 작업이야.
로그인·원격 DB·유료 API는 이번의 선행조건이 아니야.
현재 로컬 프로필과 새 이력·카드·초안은 보존하고, 기존 사진과 검토된 시연 위치를 명시 대응시켜.
옛 이미지팩 프로필로 돌아가 새 이력을 포기하거나, 사진 없는 새 프로필만 남기는 방식으로 끝내지 마.

SOURCE_AUDIT.json은 입력 ZIP 점검 결과야. 현재 앱 원인으로 단정하지 말고 실제 로딩·ID·저장·resolver를 추적해.
특히 생활팩 S01은 셔츠, 옛 팩 S01은 스니커즈야. H01도 각각 셔츠와 모자다.
같은 raw ID/이름/배열 순서로 연결하지 말고 namespace·실제 의류·자산을 명시 대응해.

mapping_candidates.review.json은 대응 후보일 뿐 확정 import 파일이 아니야.
현재 파일·종류·색·형태·프로필·장면 배치까지 검토한 후보부터 실제로 연결해.
생성된 시연 그림을 실제 브랜드 상품 사진/라벨로 확정하지 마.
없는 항목만 개별로 보류하고 가능한 사진·LED 복구는 계속 진행해.

케어는 검토된 관리 항목의 한국어 요약과 출처를 보여줘.
notes/issues/직접 open 실패/파싱 실패 같은 조사 기록을 본문이나 AI 근거로 이어붙이지 마.
그렇다고 검증 전 정보를 확인 완료로 바꾸거나 실제로 없는 관리법을 만들면 안 돼.
전체 착용 4일과 세탁 후 3회·3일은 다른 집계이니 숫자를 강제로 맞추지 마.

통합설계서·원본 팩·옷장 배경·투명 미러 UI는 보존해.
사진+LED+새 이력+케어가 같은 생활 프로필의 같은 옷에서 함께 나오는지 확인해.
홈·코디카드·달력에도 같은 사진이 반영돼야 해.
실제 전후 캡처·녹화·재적용/새로고침 검사·미해결 사유·commit을 남겨줘.
원격 운영 데이터 변경·회원가입 요구·강제 push·배포는 하지 마.
