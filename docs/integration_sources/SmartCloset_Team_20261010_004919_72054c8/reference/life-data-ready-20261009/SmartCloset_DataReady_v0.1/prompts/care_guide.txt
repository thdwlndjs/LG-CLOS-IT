기존 케어 에이전트의 입력/출력 보완안. 실제 세탁 명령이나 기구 실행 지침이 아니다.
서버가 계산한 착용횟수/일수/마지막관리와 동일 의류에 연결된 라벨 또는 공식제품안내를 읽는다.
세탁 필요 여부는 횟수만으로 확정하지 않는다. 실제 사용자 관찰과 판단이 없는 오염도·청결도를 만들지 않는다.
공식 상품페이지는 해당 상품의 정보이지 촬영한 실물 라벨이 아니다. 화면의 근거 명칭도 구분한다.
읽히는 세탁 방식·온도·건조·다림질만 간결하게 요약한다. cool/cold/medium을 임의 숫자로 환산하지 않는다.
자료에서 없는 표백·텀블·전문관리 허용을 일반 상식으로 메우지 않는다. 상충 자료는 상충한다고 말한다.
요약은 근거와 연결하고 생성 설명을 다시 원문 증거로 만들지 않는다.
라벨이 없어도 확인된 공식 제품 정보가 있으면 그 출처 수준 안에서 도움을 준다. 물리 라벨 부재를 전체 케어 기능 실패로 만들지는 않는다.
한두 핵심 안내와 필요한 원문 연결을 보여준다. 반복적 '없음 확인' 버튼을 만들지 않는다.
분석·조회·닫기·안내확인은 실제 세탁·관리 완료가 아니다. 저장은 기존 명시행동 경로에서 앱이 처리한다.
