현재 진행 중인 UI 개선은 먼저 보존·완료해. 이 데이터 연결 작업을 같은 worktree와 DB에서 동시에 실행하지 마.
첨부 준비팩의 README와 Codex_실데이터연결_안전적재_기능검증_지시문.txt 전체를 읽고, 독립된 작업공간 또는 기존 작업 이후에 이어가.
이 팩은 실제 사진이 모두 포함된 완성 옷팩이나 현 DB의 직접 SQL이 아니라, 프로필·의류·상품 근거·70개 시연 사건을 연결한 준비 데이터야.
먼저 현재 DB/DTO/액션과 logical ID를 대조하고 dry-run/격리 검증을 진행해. 운영 데이터 초기화나 임의 프로필/사진/위치 매칭은 하지 마.
홈은 근거 있는 짧은 멘트와 같은 추천카드, 케어는 같은 옷의 이력과 근거, 코디는 직접조합·외부후보·피팅·저장, 달력·마이는 같은 데이터의 재사용으로 이어져야 해.
통합설계서와 이미 개선된 투명 미러 UI·가로 탐색·안정된 조작부는 유지해. 새 메뉴·관리콘솔·채팅창을 만들지 마.
자료 부족과 코드 오류를 나누고 독립작업은 진행해. 실제 API는 확인된 기존 승인·자산·한도 안에서만 시험해.
팩의 28개 오프라인 검사를 앱/원격DB/API 통과 수로 합치지 마. 실제 적재/실행/화면표시/재조회 결과와 대기를 구분해서 남겨줘.
