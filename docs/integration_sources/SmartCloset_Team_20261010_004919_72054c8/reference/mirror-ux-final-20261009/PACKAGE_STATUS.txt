스마트 옷장 미러 UX 구현 인계 패키지 · 2026-10-09

포함:
1) 상세 Codex 작업 지시문
2) Codex 시작 메시지
3) 원본 기준 사진(파일 복사, 내용 변경 없음)
4) 미러 안전 사각형과 점광원 좌표 보조 JSON

이번 패키지에서 실제 확인한 것:
- 원본 사진 직접 열람, 1672×941 치수 확인
- 미러 안전 영역 시작값 측정
- 위치 표시 점광원 후보 34개를 원본 색상과 육안으로 확인
- 기존 영상 프레임 묶음 및 제공된 통합설계서 계약 대조
- JSON 구문, 범위, ID 중복, 참조 파일 해시 점검

아직 하지 않은 것:
- LED OFF 파생 이미지 제작
- 실제 의류 DB와 LED 위치 매핑
- 앱 코드 수정·브라우저 실행·사용성/실물 터치 검증
- 유료 API 실행, GitHub 업로드 또는 배포

동봉 JSON의 garment_ids는 의도적으로 비어 있다.
빛 좌표를 안다는 사실로 실제 의류의 위치를 안다고 해석하지 않는다.
UI 치수/모션값은 이번 구현의 시작값이며 실제 성능·인체공학 인증값이 아니다.
상세 지시문을 전달해 Codex가 구현·검수할 자료이지 완성된 앱이나 OFF 배경이 아니다.
