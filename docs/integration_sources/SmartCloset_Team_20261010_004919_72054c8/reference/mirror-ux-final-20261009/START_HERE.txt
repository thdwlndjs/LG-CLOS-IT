현재 프로젝트에서 SmartCloset_Codex_미러실물일치_두시나리오_최종지시문.txt 전체를 읽고 실행해.

이번 작업은 기존 백엔드·DB·API를 보존하면서 중앙 미러 화면과 두 시나리오를 재구성하는 작업이야.
나는 자는 동안 답하지 못하니, 지시문에 정한 범위 안에서 직접 구현→실행→캡처 확인→수정→회귀검사를 이어가.
단계마다 내 승인을 기다리지 말고 자체 검수로 다음 단계에 진행해. 계획 설명으로 끝내지 마.

references/의 원본 사진은 실제 시연 배경 기준이야. 새 옷장으로 다시 그리지 마.
원본의 LED는 켜져 있으므로, 지시문대로 LED만 국소적으로 끈 파생자산이 먼저 필요해.
mirror_geometry.reference.json은 미러와 빛의 사진상 좌표 보조값이지, 실제 의류 위치 매핑이나 완성된 OFF 자산이 아니야.

이미 있는 통합설계서 PDF·최근 영상·현재 코드도 대조하되, PDF는 변경하지 마.
예전 stage1 제한 때문에 현재 실연동을 끄거나, 옛 상의 고정 예시 때문에 이번 상의 교체를 하의 교체로 바꾸지 마.

새 비용·권한·운영 데이터 변경이 필요한 부분만 보류하고 다른 작업은 계속해.
기존 승인 범위가 없는 유료 호출·무제한 재연결·운영 배포는 하지 마.
실제 환경 한도에 도달하면 완료한 파일/commit/검사/다음 시작점을 남겨 중단 이후에도 이어갈 수 있게 해.
