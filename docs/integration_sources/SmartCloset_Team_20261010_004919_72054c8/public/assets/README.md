These six unedited garment photographs were copied from the existing local SmartWardrobe outfit-card module. `manifest.json` preserves each original PNGimg.com URL, attribution and SHA-256 hash. Its entries are developer demonstration samples, not confirmed team inventory or customer garments.

The preserved license is **Creative Commons Attribution–NonCommercial 4.0 International** (`PNGimg-license.html`). Use is limited to noncommercial demonstration; obtain suitable rights or replace the photos before commercial use. No new external images were fetched.
