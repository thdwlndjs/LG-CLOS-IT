# 스마트 옷장 최신 팀 전달본

기준 커밋 **72054c818e80db0c58b3a7808343c8279aa8713a** / 구현 **5eb809e**. 2026-10-10에 최신 작업 폴더의 현재 파일을 복사했습니다. 이전 ZIP의 재압축본이 아닙니다. 소스·이미지·생활 데이터는 그대로이며, 이 전달본에서 바뀐 것은 설치/실행 안내와 실행기·무결성 검사뿐입니다. 기준 경로와 파일별 SHA-256은 HANDOFF/SOURCE_SNAPSHOT.json과 FILE_MANIFEST.json에 있습니다.

## Windows에서 시작

1. 이 ZIP **하나**를 새 폴더에 모두 풀어 주세요. 예: C:\SmartClosetDemo. ZIP 안에서 바로 실행하지 마세요. package.json과 START.cmd가 함께 있는 폴더가 프로젝트입니다.
2. **Node.js 24.x**를 설치합니다. 이번 검증 버전은 **24.18.0**, npm **11.16.0**입니다. Git/Python/별도 DB는 실행에 필요하지 않습니다. Node 공식 사이트: https://nodejs.org/ . 설치 후 터미널을 새로 여세요.
3. 최초 한 번 **INSTALL.cmd**를 더블클릭합니다. npm 잠금파일 그대로 설치하며 인터넷이 필요합니다. node_modules는 ZIP에 없습니다.
4. **START.cmd**를 더블클릭하고 창을 유지합니다. 가입·로그인·키 입력·.env 생성 없이 실행됩니다.
5. Chrome/Edge에서 **http://127.0.0.1:4311/** 을 여세요. UI 4311, API 4312를 로컬에서만 사용합니다. 미러 시연은 넓은 가로 화면(1920×1080 권장)에서 확인합니다.

실행기가 실패해도 창이 즉시 닫히지 않습니다. 오류가 있으면 위 문구를 확인하세요. 4311/4312 포트가 사용 중이면 이전 SmartCloset 서버를 종료한 뒤 다시 실행합니다. 방화벽/인증을 끄지 마세요. 실행 후 종료하려면 Ctrl+C를 누릅니다.

PowerShell로 실행할 때:

```powershell
node --version
npm ci --no-audit --no-fund
npm run dev
```

파일 무결성: `node scripts/verify-handoff.mjs` 또는 VERIFY_FILES.cmd. 개발 검사: `npm run typecheck`, `npm test`, `npm run build`. 실제 배포는 하지 않습니다. 과거 browser 테스트는 별도 Chrome/Playwright/일부 영상 도구를 요구하며, 최초 시연의 선행조건이 아닙니다.

## 가입 없이 두 시나리오

- **김수진**: 마이 → 김수진 → 옷장 → 화이트 옥스퍼드 셔츠(S02). 사진과 왼쪽 안쪽 상단 행거의 시연 LED를 보고 착용 이력 → 라벨·관리법 → 근거 원문/관리 도움을 확인합니다. 베이지 포플린 S01은 전체 착용 4일과 세탁 후 3회·3일이 별개이며 사진 후보와 관리 원문은 개별 미확정입니다.
- **최휘재**: 마이 → 최휘재 → 홈 → 화이트 셔츠 중심 카드 → 상의만 라이트블루 셔츠(H02)로 교체. 다른 품목은 유지합니다. 카드 저장과 오늘 선택을 각각 실행하고 캘린더의 해당 날짜에서 재조회합니다. 김수진으로 갔다 돌아오거나 새로고침해도 저장한 카드·기록이 남는지 확인합니다. 실제 착용 기록은 별도 명시 조작입니다.

## 현재 동작과 데이터의 의미

투명 미러/6메뉴, 가로 탐색, 종류/검색, 프로필 분리, 의류 이력·관리 근거, 조합 교체, 제공된 외부 후보 혼합, 구성형 카드 저장/재사용, 달력, 브라우저 로컬 저장을 사용합니다. 현재 생활팩은 프로필 2명·의류 32벌입니다. 수진 사진 7/LED 5, 휘재 사진 8/LED 6이 연결되어 있습니다(15개 의류가 서로 다른 이미지 파일 12개 사용).

이름·생활 이력·상품 참고는 **시연 데이터**이며 사용자 실제 이력이 아닙니다. 의류 그림은 기존 생성 **예시 이미지**, LED는 사진 속 **시연 위치**, 관리 도움은 저장 근거의 **로컬 요약**입니다. 실제 상품/실물 라벨/물리 센서/AI 피팅 검증을 뜻하지 않습니다. 새 피팅 결과가 없으면 사람에게 입혀진 결과를 만들지 않습니다.

사진 17벌은 색·형태 충돌 또는 자료 부족으로 미연결입니다. 신발·가방 S15/S16/H15/H16은 사진만 있고 검토된 시연 수납 위치가 없어 LED가 없습니다. 검토된 한국어 상품 관리 근거는 수진 1벌/휘재 3벌이며, 검색 발췌 자료는 원문 확인 전 상태를 유지합니다. 원본 조사 메모는 보존하되 고객·AI 근거에 노출하지 않습니다. 날씨 실정보, 실물 라벨·인물·실피팅 미준비 항목은 완료로 보지 않습니다. 좁은 세로 창에서는 기존 미러 레이아웃이 잘릴 수 있습니다. 새 로컬 업로드 사진은 새로고침 후 재선택이 필요할 수 있습니다.

저장 범위는 이 브라우저/주소의 localStorage입니다. 원격 저장이나 PC 간 동기화가 아닙니다. 브라우저 데이터 삭제/시크릿 창 종료로 없어질 수 있으며 localhost와 127.0.0.1은 별도 저장영역입니다. 전달자의 개인 카드·로그인 세션·로컬 수정 기록은 포함하지 않았고, 팀원은 제공된 시연팩에서 시작합니다.

## 별도 API 설정이 필요한 기능

Supabase 앱 사용자 인증·원격 저장/재조회·비공개 사진 업로드, OpenAI 실제 에이전트, Decart 실제 피팅은 별도 계정/자산/권한/비용 확인이 필요하며 이번 전달 검증에서는 실행하지 않았습니다. 연결 코드는 보존되어 있습니다. .env.example은 빈 키 예시이고 로컬 시연에는 복사조차 필요 없습니다. 키는 본인이 서버 .env에만 설정하며, 시연을 위해 인증/RLS를 끄거나 새 DB를 만들 필요가 없습니다. 이 ZIP은 유료 실행 승인·원격 적재 승인이 아닙니다. supabase SQL은 보존용이며 자동 실행하지 않습니다.

## 인계 검증과 보존

HANDOFF/RESTORE_VALIDATION.md에 **이 ZIP을 새 빈 폴더에 풀어 진행한** 설치·빌드·실행·이미지·LED·케어·달력·저장 검사 결과를 기록합니다. 소스 버전/미커밋 상태와 포함된 기존 미추적 자산은 SOURCE_SNAPSHOT.json에 있습니다. .env·키·비밀번호·토큰·세션·개인 로그·.git·node_modules·캐시·이전 ZIP은 제외했습니다. 개인 public/local-reference는 현재 실행에 사용하지 않아 제외했습니다. 승인된 옷장 배경/필수 원본·글꼴·이미지 라이선스는 포함했습니다. reference의 과거 지시문·통합설계서 PDF는 원본 보존용이며 최신 실행 안내는 이 파일입니다.
